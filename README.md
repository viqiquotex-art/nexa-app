## Menjalankan lokal

1. Install Python 3.11+.
2. Install dependency:

```bash
pip install -r requirements.txt
```

3. Set environment variable `BOT_TOKEN` dengan token dari BotFather.
4. Jalankan:

```bash
python bot.py
```

**Jangan pernah menyimpan BOT_TOKEN di source code atau GitHub.** Untuk deployment online, masukkan token sebagai environment variable/secret pada layanan hosting.
